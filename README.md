## 📖 About Wammy
Wammy is a next-generation manga and comic reader built natively for Android using modern technologies like **Kotlin** and **Jetpack Compose**. It brings a buttery-smooth, highly customizable, and premium reading experience right to your fingertips.

By integrating directly with **Tachiyomi / Keiyoushi** extensions, Wammy allows you to effortlessly discover, organize, and read content from thousands of community-built sources across the internet.

## ✨ Features
- 🚀 **Built with Jetpack Compose**: A beautiful, fluid, and modern native Android user interface.
- 🧩 **Tachiyomi Extension Support**: Install extensions to read from thousands of different sources.
- 📚 **Robust Library Management**: Organize your manga with custom categories, dynamic grid sizing, and beautiful gradient cards.
- 🌓 **Dynamic Themes**: Beautiful Light and Dark modes, including an AMOLED Pure Black mode for battery saving.
- 🕯️ **Warm Light Mode**: Protect your eyes during late-night reading sessions with a built-in warm light filter.
- 📊 **Advanced Statistics**: Track your reading habits, total chapters read, and time spent reading with detailed analytics.
- 📥 **Offline Reading**: Download chapters straight to your device to read anywhere, anytime.

## 📥 How to Download
You don't need to compile the app yourself! You can download the latest compiled version directly from the Releases page.

1. Go to the [Releases](../../releases/latest) section of this repository.
2. Download the latest `wammy-app-release.apk` file.
3. Open the downloaded file on your Android device and tap **Install**.
   *Note: If prompted, you may need to allow "Install unknown apps" from your browser or file manager.*

## 🛠️ Built With
- [Kotlin](https://kotlinlang.org/) - First-class and official programming language for Android development.
- [Jetpack Compose](https://developer.android.com/jetpack/compose) - Android’s modern toolkit for building native UI.
- [Coil](https://coil-kt.github.io/coil/) - Image loading backed by Kotlin Coroutines.
- [Jsoup](https://jsoup.org/) - Java HTML Parser.
- [OkHttp](https://square.github.io/okhttp/) & [Retrofit](https://square.github.io/retrofit/) - Network requests and API handling.

## ⚠️ Important Note on Code Integrity
Please note that Wammy is a **reader only**. The app itself does not host, provide, or distribute any manga, comics, or copyrighted content. All content is fetched directly from third-party sources via user-installed extensions.
